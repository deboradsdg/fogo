# Como usar o F.O.G.O.

## Passo 1: Configuração do Banco de Dados

Antes de começar, é necessário criar e popular o banco de dados. Para executar essa etapa, acesse a URL abaixo no seu navegador:

- [http://localhost:8000/setup.php](http://localhost:8000/setup.php)

---

## Passo 2: Acesso ao Sistema e Credenciais

Após a conclusão da configuração inicial, acesse a tela de login:

- [http://localhost:8000/login.php](http://localhost:8000/login.php)

Escolha o perfil desejado utilizando as credenciais de teste abaixo:

| Perfil | Usuário (E-mail / Matrícula) | Senha | Acesso Permitido |
| :--- | :--- | :--- | :--- |
| **Administrador Geral** | `admin@fogo.gov.br` <br>*(ou `ADM001`)* | `senha123` | Controle total: cadastro e edição de equipamentos, histórico de auditoria, mapa e previsões. |
| **Agente de Campo** | `souza@fogo.gov.br` <br>*(ou `GT1042`)* | `senha123` | Perfil operacional restrito: atualização de situação de equipamentos com justificativa e consulta do mapa. |
